🛡️ Phishing Detection System

Learn How to Identify and Protect Against Phishing Attacks

What is Phishing?

Phishing is a type of cyber attack where attackers impersonate legitimate organizations to trick individuals into revealing sensitive information such as passwords, credit card numbers, or personal data.

🚨 Warning Signs of Phishing URLs

1. Suspicious Domain Names

Watch out for:

  • Misspelled company names (e.g., "microosft.com")
  • Extra words or characters (e.g., "paypal-secure.com")
  • Unusual domain extensions (e.g., ".tk", ".cc")

❌ Bad: amaz0n-security.tk

✅ Good: amazon.com

2. IP Address Instead of Domain

Legitimate sites use domain names, not IP addresses

❌ Bad: http://203.0.113.45/login

✅ Good: https://www.bank.com/login

3. Missing HTTPS/SSL

Secure sites use HTTPS with a padlock icon

  • Check for "https://" at the start
  • Look for the padlock icon in the address bar
  • Be cautious with "http://" (no 's')

4. Unusual URL Length

Phishing URLs are often very long

Attackers hide malicious links with excessive characters and redirects.

❌ Bad: Extremely long URLs with many parameters

✅ Good: Short, clean URLs

5. Shortened URLs

URL shorteners can hide the real destination

  • bit.ly/xyz123
  • tinyurl.com/abc
  • goo.gl/short

⚠️ Hover before clicking to see the real destination

6. Deceptive Subdomains

The real domain comes before the first '/'

❌ Bad: paypal.fake-site.com (domain: fake-site.com)

✅ Good: secure.paypal.com (domain: paypal.com)

🔒 How to Protect Yourself

1. Verify the Sender

Always check the sender's email address and domain carefully.

2. Don't Click Suspicious Links

Hover over links to preview the destination before clicking.

3. Type URLs Directly

Instead of clicking links, type the website address directly in your browser.

4. Use Multi-Factor Authentication

Add an extra layer of security to your accounts.

5. Keep Software Updated

Update your browser and security software regularly.

6. Report Suspicious Emails

Report phishing attempts to your IT department or email provider.

📊 Real-World Examples

Malicious URL Example

http://paypa1-secure-login.suspicious-site.tk/verify?user=12345

Red Flags:

  • ❌ No HTTPS (insecure)
  • ❌ Misspelled "PayPal" (paypa1)
  • ❌ Suspicious TLD (.tk)
  • ❌ Asks for verification
  • ❌ Long, complex URL

Legitimate URL Example

https://www.paypal.com/signin

Green Flags:

  • ✅ Uses HTTPS (secure)
  • ✅ Correct domain name
  • ✅ Trusted TLD (.com)
  • ✅ Simple and direct
  • ✅ Short URL
