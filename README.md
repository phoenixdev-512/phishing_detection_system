# Phishing Detection System - Educational Guide

A simple, static HTML and CSS educational resource to help users learn about phishing attacks and how to protect themselves.

## 🎯 Project Overview

This is a lightweight, educational website built with **only HTML and CSS** to teach users about:
- What phishing is and how it works
- Warning signs of phishing URLs
- Real-world examples of malicious vs. legitimate URLs
- Protection tips and best practices
- Important statistics about phishing attacks

## 📁 Project Structure

```
phishing_detection_system/
├── index.html          # Main HTML page
├── styles.css          # All styling
└── README.md          # Documentation
```

**That's it!** No backend, no JavaScript, no dependencies - just pure HTML and CSS.

## 🚀 Getting Started

### Prerequisites
- A web browser (Chrome, Firefox, Safari, Edge, etc.)
- That's all!

### How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/phoenixdev-512/phishing_detection_system.git
   cd phishing_detection_system
   ```

2. **Open the website**
   - Simply double-click `index.html`, or
   - Right-click `index.html` and select "Open with" your preferred browser, or
   - Use a local server (optional):
     ```bash
     # Python 3
     python -m http.server 8000
     
     # Then visit http://localhost:8000
     ```

## 📚 What You'll Learn

### Warning Signs of Phishing URLs
- Suspicious domain names and misspellings
- IP addresses instead of domain names
- Missing HTTPS/SSL certificates
- Unusual URL lengths
- Deceptive subdomains
- URL shorteners that hide destinations

### Protection Tips
- How to verify senders
- Why you shouldn't click suspicious links
- Using multi-factor authentication
- Keeping software updated
- Reporting phishing attempts

### Real-World Examples
The page includes side-by-side comparisons of malicious and legitimate URLs with detailed explanations of red flags and green flags.
